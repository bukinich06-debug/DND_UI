Design a modern desktop web application UI for an AI-powered text-based Dungeons & Dragons RPG.

The game is primarily text-driven. Do NOT use a traditional game map, 3D environment, character illustrations, location illustrations, or large decorative images. The world is dynamically generated by the AI, so the interface must work entirely with text, panels, icons, cards, and subtle visual elements.

## Overall visual style

Dark fantasy RPG interface with a modern premium SaaS-like UX.

The interface should feel atmospheric and immersive, but not overloaded with medieval decorations.

Use:

* dark charcoal / almost black background
* slightly lighter dark panels
* warm parchment-like accent colors for important information
* muted gold accents
* subtle borders and shadows
* elegant serif typography for important fantasy elements
* clean modern sans-serif typography for UI controls and secondary information
* restrained fantasy styling
* high readability
* generous spacing
* rounded corners used sparingly

Avoid:

* excessive medieval ornaments
* giant fantasy illustrations
* game map
* 3D graphics
* overly decorative frames
* excessive gold
* MMORPG-style UI clutter

## Main layout

Create a 3-column desktop layout.

### Left sidebar — Character

Width approximately 280px.

At the top:

* character name
* character class
* level
* small circular character avatar placeholder using a simple silhouette/icon, not an illustration

Below it:

* HP bar with current/max HP
* Armor Class
* Level / experience progress
* important character resources

Then a compact section:

* Strength
* Dexterity
* Constitution
* Intelligence
* Wisdom
* Charisma

Display abilities as compact cards with the ability score and modifier.

Below:

* Conditions / status effects
* equipped weapon
* equipped armor
* quick equipment slots

At the bottom:
buttons:

* Character
* Inventory
* Spells
* Journal

The sidebar should remain visually secondary to the main story.

## Center — Main adventure / AI Dungeon Master

This is the primary area and should occupy most of the screen.

At the top:

* current location name
* small location description such as "The Rusty Lantern — Evening"
* buttons for Journal, World, and Settings
* subtle indicator showing that the AI Dungeon Master is active

Main content is a chronological adventure log.

The conversation should visually distinguish between:

1. AI Dungeon Master narration
2. NPC dialogue
3. Player actions
4. System/game events
5. Combat events

Example:

AI narration:
"The rain has finally stopped. You enter the small tavern and immediately notice that everyone has gone silent."

NPC:
"You're not from around here, are you?"

Player action:
"You approach the bartender and ask about the missing caravan."

System event:
"Investigation check — 14"

Important events should have small icons and subtle accent colors, but the interface must remain mostly text.

The story area should feel like reading an interactive fantasy novel rather than using a conventional chat application.

## Player input

At the bottom of the central panel, create a large action input area.

Placeholder:
"What do you want to do?"

The player can type completely free-form actions.

Under the input:
small contextual action suggestions such as:

* Talk
* Inspect
* Search
* Attack
* Move
* Rest

These are suggestions, NOT mandatory buttons. The player should always be able to type any action.

Include a prominent Send / Execute button.

The input area should visually feel like the main interaction point of the entire application.

## Right sidebar — Context

Width approximately 300px.

This panel contains contextual information relevant to the current scene.

Sections:

### Current situation

Short summary of:

* location
* time
* weather
* important circumstances

### Nearby

List of discovered:

* NPCs
* locations
* objects
* points of interest

Each item should be compact and clickable.

### Party

If the player has companions, display:

* name
* class
* HP
* current status

### Quest

Display the currently active objective.

Example:
"Find the missing caravan"

With a small progress indicator and optional secondary objectives.

The right sidebar should be collapsible to give more space to the story.

## Inventory

Create a dedicated inventory overlay/modal that opens above the main game interface.

The inventory should NOT look like a traditional grid full of item pictures.

Use a clean list/card-based inventory because the game is text-based.

Inventory layout:

Top:

* "Inventory"
* search field
* category filters:
  All / Weapons / Armor / Consumables / Quest / Other
* weight indicator
* current / maximum carrying capacity

Main area:
item list with compact rows.

Each item row contains:

* small monochrome icon
* item name
* quantity
* short description
* weight
* rarity indicator if applicable
* equipped status if applicable

Example:

Iron Longsword
Weapon · 3.0 lb
"An ordinary but reliable longsword."
[Equip]

Healing Potion ×3
Consumable
"Restores 2d4 + 2 HP."
[Use]

Items should support:

* Equip
* Unequip
* Use
* Drop
* Inspect

When an item is selected, show a detail panel on the right with:

* item name
* type
* description
* properties
* weight
* value
* actions

## Important UX principle

The UI must prioritize the narrative.

The player should always feel that the AI Dungeon Master and the story are the main focus.

The inventory, character sheet, journal, quests, and contextual information are supporting systems that can be opened without leaving the current adventure.

The interface should therefore feel like:

"interactive fantasy novel + RPG character management"

rather than:

"traditional RPG game interface".

## Responsive behavior

Design primarily for desktop, but make the layout adaptable.

On smaller screens:

* collapse the left and right sidebars
* keep the story and action input as the primary screen
* open character, inventory, quests, and context as full-screen panels
